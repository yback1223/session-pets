# Security reports

For a suspected vulnerability, use
[GitHub private vulnerability reporting](https://github.com/yback1223/session-pets/security/advisories/new).
Do not post credentials, private session logs, or an exploitable issue publicly.
Include the affected version, platform, reproduction steps, and expected impact.

Only the latest published release is maintained. This is an independent project;
there is no guaranteed response time or security certification.

The macOS release is not Apple Developer ID signed or notarized. Download only
from this repository's releases and compare the provided SHA-256 checksum.
The installer does not disable Gatekeeper or alter Codex/Claude approval rules.
