# Session-Pets 사용 가이드

[README](../README.ko.md) · [English](usage.md)

## 설치와 첫 사용

배포 ZIP은 **macOS 13 이상, Apple Silicon용**입니다. Intel Mac·Windows·Linux 데스크톱은 테스트하지 않았습니다. 설치기와 소환 도우미에는 **Python 3**가 필요하며, 빌드된 앱을 쓰는 데 Node.js는 필요하지 않습니다. 다음 명령으로 Python을 확인할 수 있습니다.

```sh
python3 --version
```

[Releases](https://github.com/yback1223/session-pets/releases/latest)에서 `Session-Pets-v0.2.2-macos-arm64.zip`을 받아 압축을 풀고 `Install Session Pets.command`를 더블클릭합니다.

| 항목 | 위치 |
|---|---|
| 데스크톱 앱 | `~/Applications/Session Pets.app` |
| Codex 스킬 | `~/.agents/skills/Session-Pets` |
| Claude Code 스킬 | `~/.claude/skills/Session-Pets` |
| 설정·가져온 펫·번역 | `~/Library/Application Support/session-pets/` |

설치기는 다른 기존 스킬을 보호합니다. Python을 설치하거나 호스트 승인 정책을 변경하지 않으며, 기존 Claude 세션에 훅 플러그인을 활성화하지 않습니다.

앱은 Developer ID 서명과 Apple 공증을 받지 않았습니다. macOS가 차단하면 신뢰하는 다운로드인지 확인하고 한 번 열기를 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용하세요. [Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 참고하세요. 자동 업데이트는 없으며 새 버전은 직접 설치합니다.

앱을 연 다음 Codex에서 `$Session-Pets`, Claude Code에서 `/Session-Pets`를 호출합니다. Python 도우미를 실행하고 현재 세션 ID를 전달할 수 있는 로컬 호스트가 필요합니다. 첫 호출에서는 투명 선택기가 열립니다. **← / →**로 넘기고, 캐릭터 클릭 또는 **Enter**로 선택하며, **Esc**로 취소합니다. 이후에는 해당 세션에서 고른 펫이 다시 나타납니다. 연결할 세션마다 명령을 호출하면 세션별로 펫을 하나씩 둘 수 있고, 여러 세션의 펫이 화면에 함께 나타납니다.

앱만 직접 열면 기본 캐릭터 선택기가 나옵니다. 이 선택은 다음 선택기의 기본값을 정하며, 임의의 세션에 펫을 연결하지 않습니다. 메뉴 막대의 **🐾 아이콘**에서 기본 캐릭터를 바꾸거나 앱을 종료할 수 있습니다.

## 세션 명령

| 동작 | Codex | Claude Code |
|---|---|---|
| 소환 또는 다시 표시 | `$Session-Pets` | `/Session-Pets` |
| 선택기 열기 | `$Session-Pets choose` | `/Session-Pets choose` |
| 이 세션의 펫 숨기기 | `$Session-Pets hide` | `/Session-Pets hide` |
| 연결·상태 확인 | `$Session-Pets status` | `/Session-Pets status` |
| 고릴라 바로 선택 | `$Session-Pets gorilla` | `/Session-Pets gorilla` |
| 호랑이 바로 선택 | `$Session-Pets tiger` | `/Session-Pets tiger` |

명령 이름은 대소문자를 포함해 **모든 언어에서 `Session-Pets`로 동일**합니다. Codex 스킬 선택기에서도 고를 수 있습니다. 새 스킬이 보이지 않으면 목록을 새로 불러오거나 호스트를 다시 여세요.

소환 도우미는 현재 Codex의 `CODEX_THREAD_ID`·`CODEX_SESSION_ID`, 또는 Claude가 제공한 세션 ID를 사용합니다. 최근 대화나 폴더명으로 연결 대상을 추측하지 않습니다. 앱이 꺼져 있으면 설치된 앱을 백그라운드에서 열 수 있습니다.

## 펫 조작

| 조작 | 결과 |
|---|---|
| 한 번 클릭 또는 Enter | 원래 세션 열기 |
| 드래그 후 놓기 | 펫 이동. 연결된 작은 펫은 부모를 따라 이동 |
| 두 번 클릭 | 세션을 열지 않고 춤추기 |
| 펫 위에서 휠 | 표정 순환 |
| 우클릭 또는 `‹›` | 캐릭터 선택기 열기 |
| `×` | 이 펫 숨기기 |
| 호버 또는 키보드 초점 | 이름·설명·조작 버튼 표시 |
| 근처에서 커서 이동 | 커서를 향해 시선 이동 |
| 근처에서 커서를 빠르게 움직이기 | 웃거나 버럭하는 반응 |

고릴대장과 호들갑은 각각 16개 포즈를 갖고 있습니다. 선택기에서는 춤·웃음·분노·장난스러운 위협을 미리 볼 수 있습니다. 표정과 춤은 관찰 중인 작업 상태를 바꾸지 않습니다. macOS의 **동작 줄이기**를 사용하면 반복 움직임과 효과를 멈추고 정적인 반응을 유지합니다. 한 번 클릭은 더블클릭의 춤 동작과 구분하기 위해 260ms 뒤 처리합니다.

## 원래 세션 열기

Codex 펫은 `codex://threads/<세션 ID>`, Claude Desktop 펫은 `claude://code/continue?session=<세션 ID>`로 이동을 요청합니다. 작은 Claude 펫은 부모 대화를 엽니다.

Claude CLI 세션에서는 기록된 작업 폴더에서 `claude --desktop --resume <정확한 세션 ID>`를 실행합니다. 이 기능을 지원하는 Claude Code CLI와 Claude Desktop, 호스트에서 요구하는 로그인이 필요합니다. 실행 중인 터미널·백그라운드 세션은 Claude가 이동을 거부할 수 있습니다. 그 터미널을 사용하거나 세션 작업을 끝내고 닫은 뒤 다시 이동하세요. Session-Pets가 실행 중인 세션을 중단하거나 대체 대화를 만들지 않습니다.

이동 요청 성공은 OS나 CLI가 요청을 받았다는 의미이며, 호스트 안에 최종적으로 표시된 화면을 검증한 결과는 아닙니다. 앱이 없거나 ID가 불명확하거나 이동이 실패하면 오류를 표시합니다. 오래된 Claude 펫에 실행 위치 정보가 없다면 원래 세션에서 다시 소환하세요.

## Claude Code 플러그인

로컬 `/Session-Pets` 스킬은 소환·선택·숨기기·상태 조회를 담당합니다. **Claude 상태와 하위 에이전트 이벤트를 받으려면 해당 세션에 훅 플러그인이 활성화되어 있어야 합니다.**

Claude Code에서 실행합니다.

```text
/plugin marketplace add yback1223/session-pets
/plugin install session-pets@session-pets
```

마켓플레이스와 플러그인의 등록 ID는 소문자 `session-pets`이며, 스킬 명령은 `Session-Pets`입니다. 플러그인의 전체 명령은 **`/session-pets:Session-Pets`**입니다. 설치 후 호스트의 새로 불러오기 안내를 따르세요. 활성화되기 전의 이벤트가 나중에 다시 전달되지는 않습니다.

로컬 개발에서는 다음과 같이 플러그인 폴더를 지정해 Claude Code를 시작할 수 있습니다.

```sh
claude --plugin-dir "/절대/경로/session-pets/plugins/claude-session-pets"
```

설치된 앱에 들어 있는 플러그인도 사용할 수 있습니다.

```sh
claude --plugin-dir "$HOME/Applications/Session Pets.app/Contents/Resources/app/plugins/claude-session-pets"
```

한 세션에서는 플러그인 설치 방법을 하나만 사용하세요. 훅은 시작·도구 활동·질문·승인·응답·명시적인 하위 에이전트 시작을 전달합니다. 앱이 없으면 조용히 종료하며, 요청을 승인하거나 Claude의 판단을 변경하지 않습니다.

## 상태와 지원 범위

**작업 중 배지를 계속 띄우지 않습니다.** 답변·승인·아직 확인하지 않은 완료 알림은 호버 없이 보입니다.

| 표시 | 의미 |
|---|---|
| 답변 필요 | 지원하는 구조화된 질문에 답변을 기다리는 중 |
| 승인 필요 | 지원하는 Claude 계획·권한 요청의 승인을 기다리는 중 |
| 작업 완료 | 명시적인 Codex 턴 종료 기록을 확인함 |
| 응답 도착 · 완료 미확인 | Claude 응답은 확인했으나 작업 종료는 확정할 수 없음 |
| 상태 미확인 | 현재 세션 상태를 판정할 수 없음 |

질문 배지를 누르면 원래 세션을 열며, 질문 대기 표시는 유지합니다. 일치하는 답변·실패, 새 턴 또는 명시적 중단으로 요청이 해결되면 표시를 내립니다. 여러 질문은 각각 해결될 때까지 대기 상태를 유지합니다. 접수된 Codex 비동기 질문은 AI 응답 생성이 끝났다는 이유만으로 해결 처리하지 않습니다.

완료 배지는 Session-Pets에서 완료된 세션으로 이동 요청을 성공했을 때, 지원하는 Codex 로컬 읽음 기록에서 해당 결과를 읽은 것으로 확인했을 때, 또는 새 턴이 시작됐을 때 사라집니다. 세션 열기가 실패하면 유지합니다. 읽음 처리는 알림을 지우며, 기록된 완료 상태 자체를 바꾸지 않습니다.

### Codex

질문·완료 흐름은 로컬 macOS 테스트 환경에서 검증했습니다. 앱은 연결된 특정 세션의 실행 기록을 관찰하고, 일치하는 `task_started`·`task_complete` 생명주기 기록을 요구합니다. 개별 도구가 끝났거나 AI가 완료라고 말한 것만으로는 충분하지 않습니다. **작업 완료는 Codex 턴의 종료**를 뜻하며, 사용자의 모든 요구사항이 독립 검사를 통과했다는 의미가 아닙니다.

`request_user_input`·`request_user_input_async`의 구조화된 호출을 ID와 답변으로 추적합니다. 별도의 Codex 권한 승인 자동 감지, 하위 에이전트 자동 발견, 세션 간 연결은 지원하지 않습니다.

처음에는 로그의 최근 4MiB를 읽으며, 현재 턴 시작을 찾기 위해 최대 16MiB까지 넓힐 수 있습니다. 이후 약 1초 간격으로 추가 기록을 확인합니다. 미종료 턴에 90초간 유효한 갱신이 없으면 상태 미확인으로 바뀝니다. 오래 걸리는 무출력 도구 실행도 여기에 해당하며, 확인된 질문 대기에는 시간 제한을 적용하지 않습니다. 파일 누락·읽기 실패·형식 불일치도 미확인으로 두고 재시도합니다. 호스트 로그 형식이 바뀌면 연동 수정이 필요할 수 있습니다.

### Claude Code

플러그인은 `AskUserQuestion`·`ExitPlanMode`·MCP 입력 요청·권한 알림을 배지에 연결합니다. 훅 전송과 화면 반영은 로컬 입력 자료로 검증했습니다. 실제 Claude 모델이 질문을 생성하는 전체 흐름은 검증하지 않았습니다.

`Stop`·`SubagentStop`은 응답 관찰을 뜻합니다. 다른 훅이 작업을 이어갈 수 있으므로 **최종 완료의 증거로 사용하지 않습니다.** 일치하는 턴 ID가 없으면 상태 미확인입니다. 응답 도착만으로 완료 연출이나 자동 퇴장을 하지 않습니다.

작은 펫은 명시적인 하위 에이전트 시작 이벤트를 받은 뒤, 부모 펫이 연결된 경우에만 나타납니다. 실제 외부 하위 에이전트의 확정 완료·자동 퇴장은 지원하지 않습니다. 완료 연출은 격리된 관리형 검사에서만 실행했습니다. 대기 중인 요청이 없는 관찰 상태는 90초간 새 이벤트가 없으면 미확인으로 전환하며, 이후 유효한 이벤트를 받으면 추적을 복구합니다.

## 언어

펫과 세션 선택기는 대화 언어가 아니라 **연결한 호스트의 표시 언어**를 따릅니다. Codex의 `desktop.localeOverride` 또는 Claude Desktop의 `locale`을 우선하고, 다음으로 macOS의 앱별 언어, 시스템 언어를 확인합니다. 기본 선택기는 시스템 언어를, 공통 메뉴는 마지막으로 활성화한 호스트 언어를 따릅니다.

한국어와 영어는 내장되어 있습니다. 다른 언어에서는 스킬을 처음 호출할 때 기존 Codex·Claude 세션이 UI 문구를 번역해 `~/Library/Application Support/session-pets/languages/`에 저장합니다. 별도 번역 API 키는 필요하지 않습니다. 기존 호스트의 모델과 로컬 파일 실행 권한을 사용하므로 해당 호스트의 일반 사용 조건과 사용량은 그대로 적용됩니다. 키·치환 변수는 검사한 뒤 적용하며, 모든 언어의 번역 품질을 검수한 것은 아닙니다.

유효한 번역이 없으면 영어로 표시합니다. 새 언어로 바꾼 뒤에는 `Session-Pets`를 한 번 호출하세요. 설치된 스킬 설명은 호스트가 다시 읽은 뒤 갱신되고, 명령 이름은 바뀌지 않습니다. 세션 제목과 사용자 펫 이름도 유지합니다. 오른쪽에서 왼쪽으로 쓰는 언어는 그 방향으로 배치하되, 선택기 방향키는 실제 좌우 방향을 유지합니다.

## 커스텀 펫

선택기의 **＋ 내 펫 추가**를 누릅니다. 투명 **PNG** 한 장은 모든 상태에서 같은 그림으로 표시합니다. 스프라이트 애니메이션을 쓰려면 PNG와 JSON 명세 파일을 같은 폴더에 두고 JSON을 가져오세요.

다음은 1536 × 1024 PNG를 512 × 512 크기의 여섯 칸으로 나누는 예입니다.

```json
{
  "version": 1,
  "name": "나의 펫",
  "image": "my-pet.png",
  "columns": 3,
  "rows": 2,
  "states": {
    "idle": [0],
    "working": [1],
    "waiting": [2],
    "done": [3],
    "error": [4],
    "sleep": [5]
  }
}
```

프레임 번호는 왼쪽 위 `0`부터 가로 방향입니다. 상태별 배열에 여러 번호를 넣으면 초당 약 7프레임으로 순서대로 재생합니다. `idle`은 필수이며, 생략한 상태는 이를 재사용합니다. `working`은 그림의 애니메이션 상태이며, 작업 중 배지를 표시한다는 뜻은 아닙니다.

추가 상태는 `unknown`, `observed`, `dance`, `laugh`, `angry`, `threat`, `surprised`, `curious`, `drag`, `blush`, `greeting`입니다.

| 제한 | 최댓값 |
|---|---|
| PNG | 12MiB |
| JSON | 64KiB |
| 이미지 크기 | 각 변 8192px, 총 2400만 화소 |
| 스프라이트 격자 | 256칸. 이미지 크기가 행·열로 나누어떨어져야 함 |
| 상태별 재생 배열 | 프레임 번호 256개 |
| 펫 이름 | 40자 |

이미지 참조는 JSON이 있는 폴더 내부에 있어야 합니다. 외부 URL과 해당 폴더 밖 경로는 거부합니다. 잘못된 파일을 가져와도 기존 펫은 바뀌지 않습니다. 성공한 가져오기는 앱의 로컬 데이터 폴더에 복사합니다.

## 로컬 데이터와 권한

앱은 소유자만 접근하는 `0600` 권한의 로컬 Unix 소켓을 사용하며, 텔레메트리·분석 클라이언트가 없습니다. Session-Pets 계정이나 별도 API 키도 필요하지 않습니다. 호스트 자체의 계정·네트워크 동작·모델 요금·실행 권한은 그대로 적용됩니다.

- **Codex:** 연결된 세션 로그, 지원하는 로컬 읽음 기록, 호스트 언어 설정을 읽습니다. 대화 사본을 별도로 저장하지 않습니다.
- **Claude:** 훅은 프롬프트 본문·도구 입력·전체 대화 파일을 제외합니다. 최근 AI 응답은 최대 60,000자까지 전달될 수 있으며, 메모리에만 보관하고 앱 설정 파일에는 저장하지 않습니다.
- **로컬 저장:** 세션 ID·제목·작업 폴더·펫 선택·위치·표시 여부·완료 알림 확인 기록·가져온 이미지·번역을 저장합니다. 설치된 스킬 중 Session-Pets 소유로 표시된 항목의 언어 메타데이터만 갱신합니다.

질문 본문과 답변은 펫에 표시하지 않습니다. 앱이 권한을 승인하거나 작업 프롬프트를 보내거나 모델을 바꾸거나 세션을 중단하지 않습니다. 경로와 처리 범위는 [개인정보 안내](PRIVACY.md)에서 확인할 수 있습니다.

## 문제 해결

| 문제 | 확인할 내용 |
|---|---|
| 설치기가 Python이 없다고 알림 | `python3`를 사용할 수 있게 한 뒤 다시 실행. Python은 자동 설치되지 않음 |
| 스킬이 이미 존재함 | 안내된 폴더 확인. 다른 스킬을 보호하기 위한 중단일 수 있음 |
| 명령이 목록에 없음 | 스킬 목록 갱신 또는 호스트 재시작. `Session-Pets` 대소문자 확인 |
| 현재 세션 ID가 없음 | 관계없는 셸이 아니라 지원하는 로컬 세션 안에서 호출 |
| 앱은 열렸는데 세션 펫이 없음 | 세션에서 소환. 기본 선택기만 열면 연결되지 않음 |
| Claude 상태가 갱신되지 않음 | 해당 세션의 훅 플러그인 활성화 확인. 로컬 스킬만으로는 부족 |
| 질문을 감지하지 못함 | 지원하는 구조화된 요청만 관찰. 일반 문장 질문은 상태 이벤트가 아님 |
| 상태 미확인 | 호환되는 로컬 기록·훅 확인. 긴 무출력 도구 작업은 90초 관찰 제한에 걸릴 수 있음 |
| Claude 펫 클릭 실패 | Desktop·로그인·작업 폴더·실행 중 CLI 제한 확인. 오래된 펫은 다시 소환 |
| 새 언어가 계속 영어로 보임 | 해당 호스트 언어에서 스킬을 호출하고 로컬 번역 파일 쓰기 허용 |

## 개발 검사

Node.js 22.12 이상, npm, Python 3가 있는 소스 폴더에서 실행합니다.

```sh
npm ci
npm start
```

앱 빌드와 로컬 세션 스킬 설치:

```sh
npm run pack
npm run install:integrations
```

제공하는 검사:

```sh
npm test
npm run smoke
```

`npm test`는 단위 검사를 실행합니다. `npm run smoke`는 격리된 로컬 데이터 폴더에서 이 앱의 화면을 실행하고 `work/smoke/`에 캡처를 저장합니다. 외부 앱을 조작하거나 실제 모델 요청을 보내지 않습니다. Smoke 모드는 소스 전용이며, 패키징된 앱은 `--smoke-test`로 진입하지 않습니다. 단위 검사와 로컬 입력 자료 검증이 모든 호스트 연동의 실제 실행을 입증하지는 않습니다.

## 제거

**🐾 메뉴**에서 종료한 뒤 `~/Applications/Session Pets.app`을 지웁니다. 로컬 명령도 없애려면 `~/.agents/skills/`·`~/.claude/skills/`의 `Session-Pets` 폴더를 제거합니다. Claude 플러그인을 활성화했다면 Claude Code의 플러그인 관리자에서 제거하세요.

설정과 가져온 이미지는 `~/Library/Application Support/session-pets/`에 남습니다. 이 폴더를 지우기 전에 보관할 이미지를 백업하세요.
