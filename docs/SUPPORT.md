# Session-Pets support

Session-Pets is a free, independent project maintained by
[yback](https://github.com/yback1223). Support is handled in the public
[GitHub issue tracker](https://github.com/yback1223/session-pets/issues).
There is no paid support plan or guaranteed response time.

Before opening an issue, read the [installation and troubleshooting guide](usage.md)
([한국어](usage.ko.md)) and check for an existing report. Include the Session-Pets
version, macOS version and chip, host app and version, steps to reproduce, and
what you expected to happen. Screenshots are useful when the problem is visual.

Remove private session titles, paths, conversation text, account details, and
credentials from anything you post. Do not attach your full Codex or Claude
history. If the report concerns a vulnerability or exposed private data, use
[private vulnerability reporting](https://github.com/yback1223/session-pets/security/advisories/new)
instead of a public issue; see [SECURITY.md](../SECURITY.md).

The current desktop release supports macOS 13 or later on Apple Silicon and
requires Python 3 for the session helpers. The app and plugin must both be
installed as described in the guide. Host subscriptions, model access, and
account problems are handled by the relevant host provider.
